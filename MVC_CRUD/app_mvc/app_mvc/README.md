# Aplicativo MVC (Python + Tkinter + SQLite)

Executar: `python main.py`  (Python 3.8+, sem dependências externas)

    main.py
    database.py            # conexão e criação das tabelas (app.db)
    models/                # acesso ao SQLite (CRUD)
    views/                 # telas Tkinter (sem regra de negócio)
    controllers/           # validação e ligação Model <-> View
